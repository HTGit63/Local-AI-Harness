# Product

Gemma 4 Harness is a local web-first coding harness for Chat Mode and Agent
Mode work against local models.

Primary users:

- local developer running Ollama models
- developer testing agent planning/tool/diff/verification behavior

Core capabilities:

- direct Chat Mode without repo tools
- Agent Mode with workspace inspection, planning, tools, approvals, diff, tests
- explicit runtime identity
- durable redacted run logs
- safe session cleanup
- opt-in real-model smoke
